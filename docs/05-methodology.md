# Methodology: How This Catalog Was Built and Is Maintained

## The VAULT prompt stack

The catalog is the output of a ten-stage VAULT run executed 2026-09-11:

| Stage | Name | Output |
|---|---|---|
| VLT-0 | Scope Lock | `docs/00-scope-lock.md` |
| VLT-1 | Taxonomy & Ontology | `docs/01-taxonomy-ontology.md` |
| VLT-2..5 | Discovery Sweeps (one per category) | Candidate lists, provisionally tiered |
| VLT-6 | Master Asset Catalog | `catalog/` and `data/catalog.json` |
| VLT-7 | Evidence Grading | `docs/02-evidence-tiers.md` |
| VLT-8 | Strategic Landscape | `docs/03-strategic-landscape.md` |
| VLT-9 | Serialization, Executive Summary, Commercialization | `data/`, `docs/04-commercialization.md` |

The executive summary is always composed last, from the synthesis, never first.

## Research discipline applied

- Vocabulary-size claims were checked against multiple sources where possible;
  where sources genuinely disagree (Klingon, Na'vi), every figure is recorded
  with its own tier rather than averaged or adjudicated.
- All self-reported numbers are quarantined at STATED regardless of the parent
  asset's tier.
- Dictionary and paper citations carry edition-level locators (publisher, year,
  ISBN or arXiv id).
- Null results are recorded as findings (the Na'vi NLP gap; the absence of any
  standards-compliant conlang metadata).
- No lexicon content is reproduced. The catalog cites dictionaries; it does not
  copy them.

## Maintenance model

1. **Canonical source:** `data/catalog.json`. All edits happen here.
2. **Derived artifacts:** `data/catalog.csv`, `data/metrics.csv`,
   `data/ecosystem-edges.csv`, and the roll-up table. Regenerated by
   `scripts/build_derived.py`; never hand-edited.
3. **Drift gate:** `data/checksums.sha256` holds SHA-256 digests of every
   derived artifact. `scripts/drift_gate.py` fails if a derived file no longer
   matches its manifest entry, which catches hand edits and stale builds alike.
4. **Quality gate:** `scripts/validate_catalog.py` checks every record against
   the JSON Schema plus house rules the schema cannot express (metric tier
   tags, rights flags, id format, STATED quarantine on self-reported metrics).
5. **Style gate:** `scripts/dash_gate.py` scans raw bytes for em and en dashes
   across all prose and data files.
6. **CI:** `.github/workflows/quality-gate.yml` runs all gates on every push
   and pull request.

## Correction ledger

Corrections are numbered tickets (C-001, C-002, ...) opened as GitHub issues
and closed in the CHANGELOG. The ledger is part of the product; silent
correction is prohibited by the framework.

## Update cadence

- Quarterly: vendor metric re-verification (Duolingo, app stores, fan-site
  self-reports)
- Annually or on release events: canon expansions (qep'a', naviteri.org, new
  franchise releases), new academic corpora
- On demand: community-submitted corrections and additions per CONTRIBUTING.md

## Reproducing the full gate locally

```bash
python3 scripts/validate_catalog.py && \
python3 scripts/build_derived.py && \
python3 scripts/tier_rollup.py && \
python3 scripts/dash_gate.py && \
python3 scripts/drift_gate.py && \
echo "ALL GATES PASSED"
```

Standard library only; no environment setup required beyond Python 3.9+.
