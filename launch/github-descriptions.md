# GitHub Repository Descriptions: BHIL-VAULT-CONLANG

Three options, each programmatically verified at or under 350 characters (see character counts).

## Option 1 (241 characters)

Evidence-graded catalog of the fictional conlang data universe: Klingon, Elvish, Dothraki, Na'vi and more. JSON-LD with DCAT, schema.org and Croissant crosswalk, five-tier evidence discipline, stdlib Python gates. A BHIL VAULT framework run.

## Option 2 (219 characters)

The data landscape of invented languages, catalogued like it matters: datasets, institutions, scripts and tools with evidence tiers, rights flags and a machine-readable JSON-LD core. Built with the BHIL VAULT framework.

## Option 3 (239 characters)

Open knowledge base mapping the datasets, canon guardians, scripts and tooling of fictional constructed languages. Every claim tiered, every self-report quarantined, every derived file drift-gated. BHIL VAULT framework, dual MIT and CC BY.

## Recommendation

**Option 3.** It leads with "open knowledge base," names the four asset classes, and states the three quality mechanisms (tiering, quarantine, drift gates) that differentiate this from a link list. Option 1 is the strongest for search (names the famous languages) and is the right choice if discovery via language names matters more than the governance story. Option 2 is the most voice-forward but the least specific.
